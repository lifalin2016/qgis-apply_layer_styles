about=Adds an "Apply Styles" entry to the bottom of a vector layer's right-click "Styles" submenu in the Layers panel. Choosing it opens a dialog listing every other vector layer in the project that shares the same geometry type (point / line / polygon), with a text box to filter the list by name. Check one or more layers and press OK to copy the source layer's full style (symbology, labeling, etc.) onto them.
